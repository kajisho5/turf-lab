# 回収率100%超の探索（2026-07-19 夜間）

**依頼**: 回収率100%を超える手法を見つける。
**結果**: **見つからなかった。** 加えて、なぜ構造的に難しいかが定量的に分かった。
そして**既存の看板である高知ファイナル⭐フォメ156%が再現できなかった**（要対応）。

データ: keiba.go.jp 公式 2013-2026、**178,461レース**（ばんえい除く全14場）。
`backtest/build_dataset.py` で生成。ROIの分母は全て「買った全レース」。

---

## 1. 結論から

| 探索 | 最高ROI |
|---|---|
| 買い方43種の総当たり（全場・17万R） | **87.9%**（1番人気複勝） |
| 条件別スキャン（場・頭数・距離・クラス・R番号・レース名） | **92.2%**（名古屋8-9頭の1番人気複勝） |
| 人気別の単勝・複勝 | **88.3%**（1番人気複勝） |

**100%を超えたものは1つも無い。** 天井は約90%。

探索は train=2013-2022 / holdout=2023-2026 に分けた（何百通り試せば偶然100%超が出るため）。
train と holdout の数字はほぼ一致しており、手法自体は安定している。

---

## 2. なぜ超えられないか（構造的な壁）

### 控除率の実測（全通り買いのROI = 1 − 控除率）

| 券種 | 全買いROI | 実質控除率 |
|---|---|---|
| 単勝 | 69.4% | 30.6% |
| 複勝 | 70.4% | 29.6% |
| ワイド | 62.0% | 38.0% |
| 馬単 | 57.7% | 42.3% |
| 3連単 | 54.8% | 45.2% |
| 馬連 | 55.2% | 44.8% |
| 3連複 | 50.1% | 49.9% |

**券種が複雑になるほど壁が高い。** 3連系は半分近く持っていかれる。
「フォーメーションで当てる」方向は、控除率の観点から最も不利。

### favorite-longshot bias（人気薄が過剰に買われている）

| 人気 | 単勝ROI | 複勝ROI |
|---|---|---|
| 1番 | **78.6%** | **88.3%** |
| 2番 | 76.6% | 81.3% |
| 3番 | 74.7% | 76.0% |
| 5番 | 74.3% | 70.6% |
| 8番 | 63.5% | 64.7% |
| 10番 | 54.9% | 59.8% |
| 12番 | 47.5% | 54.8% |

各人気帯 17万サンプル。**人気馬に寄るほど回収率が高い**という、きれいな単調関係。

これは地方競馬の市場が「効率的すぎる」のではなく、**人気薄が割高に買われている**ことを意味する。
夢を買う資金が人気薄に流れ込むため、期待値は人気薄ほど悪い。

**これが最重要の発見。** 「人気薄を狙う」戦略は、控除率に加えてこのバイアス分だけ余計に不利。
⭐（人気薄4-8番人気×先行）はまさにこの逆風の中で戦っている。

## 3. 高知ファイナル⭐フォメ 156% が再現できなかった

### やったこと
kochi.html の `kochiSpecialScore` を忠実に再構成した（前回の失敗を修正）。

```
s     = 3.0*jk + 1.5*wk + 1.0*sr + 1.5*kochiFormScore
spp   = softmax(s/0.5)
blend = spp + 2*mp  （1番人気×0.72 / 4-5番人気×1.18 / 6-7番人気×1.10）
実力上位 = blend降順 / ⭐ = 4-8番人気 かつ styleType=front
```

`styleType` は「近走の**平均**位置」ではなく「**前で運んだ走の重み付き割合が45%以上**」である点を
再現した（平均で判定すると⭐がほとんど出ず、最初これで失敗した）。

### 選抜はほぼ一致した
| | AUDIT | 今回 |
|---|---|---|
| ⭐率（人気薄のうち） | 約30% | **29.8%** |
| ⭐≧2 で買えるレース数 | 638R | **631R** |

### しかしROIが合わない
| | AUDIT | 今回 |
|---|---|---|
| ROI | **156%** | **57.1%** |
| 的中率 | 9.1% | 7.6% |
| 的中配当の中央値 | 589倍 | 334倍 |

ブートストラップ（レース単位・1万回）: **95%信頼区間 39%〜77%、100%超の確率 0.0%**。

### 再現の限界（フェアに書く）
2026年3月以降は実オッズがあるので、人気での代用と突き合わせた（42R）:

- **⭐の集合は実オッズ版と100%一致** → ⭐の選抜は正しく再現できている
- **上位5頭の順序は11.9%しか一致しない** → 2着・3着の相手選びは再現できていない

つまり「1着固定の⭐は合っているが、相手が違う」状態。相手が違えば的中率は下がるので、
57%という数字は過小評価の可能性がある。**156%を完全に否定はできない。**

ただし的中配当の中央値が 334倍 vs 589倍 と大きく違う点は、相手選びだけでは説明しづらい。

### 推奨対応
1. **156%という数字の公表を一旦止める。** 検証が取れていない状態で外に出す数字ではない
2. 決着させるには**アプリの実コードを直接回す**しかない（h3.js方式のps注入）。
   実オッズは2026年3月以降しか無いので、netkeibaの過去オッズを別途集める必要がある
3. §2 の構造（3連単の控除率45%＋人気薄バイアス）を踏まえると、
   **156%が本物なら極めて異例**。まず疑うべき数字だと考える

## 4. 検証した戦略の一覧（すべて100%未満）

対照群 / モデル◎（単・複・ワイド・馬連・馬単・3連複BOX）/ 人気薄×先行（単・複・ワイド）/
⭐1着固定3連単フォメ（3着5・7・9・12頭）/ スコア差gap 2・4・6・8 で絞る /
◎の人気帯で絞る（1・2-3・4-6・7-20）/ 先行数で絞る（1・2・3頭以下）/
少頭数（7頭以下）/ 多頭数（14頭以上）/ 当地複勝50%以上 …計43種。

条件別スキャンでは 場14 × 頭数7帯 × 距離7帯 × R番号12 × レース名キーワード15 も見た。

**「ファイナル」「記者選抜」は1番人気勝率が22-27%と確かに極端に低い**（市場が歪んでいる）。
しかしその条件でも⭐複勝ROIは57-61%と、むしろ全体平均より悪い。
**市場が歪んでいることと、そこから利益が取れることは別。**

## 5. ここから先に望みがあるとしたら

公開データ（着順・人気・通過順）だけで組んだ戦略は、この探索でほぼ出尽くしている。
残る方向は3つ。いずれも簡単ではない。

1. **オッズの時系列**（締切直前の資金の動き）。現在のアプリの元コンセプト「異常オッズ・資金流入」は
   まさにこれだが、**スナップショットを記録する仕組みが無いので検証できない**。
   まず記録を始めないと、1年後も同じ場所にいる。AUDIT v352 でも同じ指摘がある
2. **人気馬側**。バイアスは人気馬が割安だと言っている。1番人気複勝の最良条件で92%。
   ここから100%に乗せるには「1番人気が飛ぶレースを避ける」判別が要る
3. **控除率の低い券種に絞る**。単複（30%）以外は最初から不利。3連系は捨てる

---

## 6. 正直な総括

**回収率で勝つ手法は見つからなかった。** 17万レース・43戦略・条件別スキャンを通して、
天井は約90%だった。これは控除率30-50%と人気薄バイアスの二重の壁による。

FACTS.md の「地方の平場は回収率で稼げない」という既存の結論は、より広い検証で**追認された**。
さらに今回、**唯一の例外とされていた高知ファイナル⭐フォメも再現できなかった**。

予想の価値は回収率ではなく精度（当たっている感）にある、という方針が正しい。
そして「回収率重視」を看板に掲げるのは、手元のデータと矛盾する。
