#### 2.5. キャリーオーバー監視（WIN5 / トリプル馬単）★理論上唯一の +EV 機構
**なぜ重要か**: 17万レースの探索で回収率100%超は1つも見つからなかった（天井92.2%）。
壁は控除率30-45%と人気薄バイアス。**キャリーオーバーはその壁を構造的に下げる唯一の仕組み**。

繰り越された金は**再度の控除を受けない**ので、算数が単純に成立する:

```
当該回の売上 = P、キャリーオーバー = C、払戻率 = 0.70
  払戻総額 = 0.70 × P + C
  全体の回収率 = (0.70P + C) / P = 0.70 + C/P

  → C / P > 0.30 なら、その回は**全体として回収率100%超**
```

トリプル馬単: 払戻率70%（控除率30%）、的中者なしでキャリーオーバー。
10円あたり6000万円の上限を超えた分も繰り越される。**キャリーオーバーは主催者別に繰り越し**。
WIN5 も同じ構造（払戻率70%・キャリーオーバーあり）。

##### やること
1. **キャリーオーバー額と売上を毎回記録する**（南関は nankankeiba.com の払戻・キャリーオーバー欄）
2. `C / P > 0.30` を満たす開催を検出して通知
3. 満たした回の実績を蓄積して、理屈どおりに回収率が出るか検証

##### 正直な注意（ここを外すと机上の空論になる）
- **全体で+EVでも、自分の買い目が+EVとは限らない。** 全体ROIは「その回の全投票の平均」。
  当てにいく買い方が群衆平均より下手なら、+EVを取り逃す
- **自分の投票がPを増やす（希釈）。** プールが小さいほど影響が大きい。
  地方の特殊馬券はプールが小さいので、大きく張るほど自分で条件を壊す
- **分散が極端。** 3レース連続の馬単。的中率は極めて低く、資金が尽きる方が先に来る
- **上限6000万円**（10円あたり）を超えた分は繰り越されるので、超高額配当は満額取れない

##### なぜ今まで見つからなかったか
17万レースの検証は**単勝〜3連単の通常券種**だけを見ていた。キャリーオーバー型の特殊馬券は
payback.csv に無く、検証の対象外だった。**盲点だった。**

## やらないこと（意識的に）

| やらない | 理由 |
|---|---|
| 新しい因子を足して複勝率を上げる | 61.7%→63%にしても控除率20-25%に阻まれて100%を超えない。馬体重・レース間隔・逃げ被り・展開逆転・重賞傾向は検証済みで全部却下 |
| 3連系を主力にする | 控除率が実測で3連複49.9% / 3連単45.2%。最初から不利 |

| スコアをPHPに移植 | GBMとスコアリングの二重実装になる。片方だけ直して食い違う未来 |

## 発信の方針（フォロワー10万人に向けて）

**「回収率で勝てる」とは言わない。** データがそう言っていないので、いずれ矛盾が露呈する。

代わりに言えること:
- **当たる**（◎複勝61-63%。モデル◎の平均人気2.5番で健全）
- **買わないレースを決められる**（狙い目以上に絞ると78.3%→84.3%、投資は35分の1）
- **検証の透明性**（負けた検証を公開できるのは、データを持っている人だけの特権）

予想アカウントは無数にあり、ほぼ全部が「3連単◯◯万円的中！」をやっている。同じ土俵では埋もれる。
**「今日は見送りです」と言える唯一のアカウント**は差別化になる。買わせないことが信頼を生む。
