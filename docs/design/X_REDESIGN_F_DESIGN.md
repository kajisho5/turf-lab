## 4. 共通の形
- 上に二重線（太6px＋細2px）→ 見出し（明朝・80〜96px）→ 右上に日付など → 細線 → 凡例1行（22px）。
- 枠は角を丸めない。★勝負＝生成りの太枠（4px）＋上に赤い帯（10px）／狙い目＝赤い枠（3px）／先行推奨・見送り＝灰の点線／ふつう＝弱い線（2px）。
- レース番号は四角い札（74×52）。★勝負だけ赤、ほかは生成り。
- ◎の行だけ帯を敷き、左に赤い縦線（6px）。◎の馬名は30px・太字、ほかは27px。
- 脚質（逃・先・差・追・自在）は灰の小さい枠。色分けはやめる（今は4色）。
- ◎○の点数は数字だけ（今ある横棒はやめる。長い馬名と重なるため）。
- 下に細線 → 注記（22px）。今ある下の色つきの帯はやめる。
- 字はどれも22px以上。

## 5. 画像ごとの違い
- **今日の★勝負**：1レース1枠（2列）。時刻・場とレース番号の札・クラスと距離／◎（40px）／強み（生成りの札＋文）／○。
- **場ごとの予想**：見出しは場の名前（96px）。右上の赤い札に「★勝負 n　狙い目 n」。枠の右上に札（★勝負／狙い目／先行）。天気は収まる時だけ出す。
- **答え合わせ**：見出しの横に「答え合わせ」の札。着順は 1着＝金／2・3着＝生成り／着外＝灰。下の行は 的中＝金、なし＝灰。見送りは点線。
- **回収率**：表（券種・回収率・的中）。100%以上は金、未満は灰。合計の3行は枠つき、総合計は太枠。今ある「どこまで買うか」の段も同じ表の形で残す（見本では省略）。
- **場別回収率**：表（場・レース・推奨・見送り込み・狙い目）。全場の行は太枠。
- **週間・月間まとめ**：大きい数字3つ／区分ごと／（週間）日ごと・（月間）新旧モデル／いちばんの的中。

## 6. 進め方
1. `THEME_F` と共通の描き方（見出し・枠・札・行）を足す。
2. 5つの関数を1つずつ置き換える。置き換えるたびに、本番ページで同じ日の画像を新旧で作り、**載っている文字と数字が同じ**ことを確かめる（見た目だけが変わっていること）。
3. 12レースの場・★勝負0件の日・長い馬名（9文字）・同着・中止のレース、で崩れないか見る。
4. sw.js のバージョンを上げる。docs/SCORING_AUDIT.md に追記。
- 投稿の回（8:30・22:30）の前後30分は公開しない（今日の事故の教訓）。
- 切り替えは全部まとめて1回（朝と夜で見た目が混ざらないように）。
