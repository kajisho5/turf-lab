見本：docs/design/redesign2/ の d01〜d10（.svg／.png）と、10個を並べた sheet.png。作り方は gen.py。名前と数字は全部架空。
**ここは案を選ぶ段階。選ばれた1つについて、全部の画像ぶんの設計書と見本を作ってから実装する。**
今の本番は F案（新聞・夜）のまま動いている。決まるまで変えない。

前回（A〜F）は色と書体を替えただけで、どれも同じ形だった。今回は、競馬にしか無いものから形を作った。

## おすすめ
**1（枠の色）**。馬番の色がそのまま競馬場で見る色と同じなので、見る人の役に立ち、ほかのアカウントの画像と一目で区別がつく（比較は未調査・印象）。
次点は **8（ゲート）**＝1を一歩進めた形、**5（中継テロップ）**＝いちばん勢いがある。
