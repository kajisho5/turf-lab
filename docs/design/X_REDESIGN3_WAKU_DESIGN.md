## 1. 何を変えるか
- 対象: 今日の★勝負 / 場ごとの予想 / 答え合わせ / 回収率・場別回収率 / 週間・月間まとめ（地方・中央とも）

## 2. 決まり
- **色は枠の色だけ**（1白 2黒 3赤 4青 5黄 6緑 7橙 8桃）。それ以外は白と灰色だけ
- ★勝負・狙い目・的中は色ではなく「形」で区別する
  - ★勝負＝白い太枠＋白地の札 / 狙い目＝細い枠＋白線の札 / 先行推奨＝点線 / 見送り＝斜線＋灰色
  - 的中＝白い太枠、1着＝白地の札、3着内＝白い太字、それ以外＝灰色
  - 回収率は 100%以上＝白い太字、未満＝灰色（赤・緑は使わない）
- 中央と地方は同じ見た目（区別は見出しの文字で）

## 3. 色と文字
| 用途 | 値 |
|---|---|
| 背景 / 箱 / 線 | #0e1014 / #181b22 / #3a3f4a |
| 文字 / 薄い文字 | #f5f6f8 / #9aa3b2（箱の上で約6.9:1） |
| 枠 1〜8 | #f4f4f4 #1a1a1a #e23a2e #2f73e0 #f4cf1f #2fa35a #f28c28 #f4a3c0（文字は 1・5・7・8 が黒、他は白。2枠は灰色の縁どり） |

- 文字: 日本語 Noto Sans JP（400/500/700/900）、数字 Barlow Condensed（500/700）。どちらも SIL OFL。実装時は公式の配布元と最新バージョンを確認して `fonts/` に自前で置く（今の Noto Serif JP / Roboto Condensed は使わなくなる）
- いちばん小さい文字は 22px（画像の横幅 1240px）

## 4. 枠の番号の決め方
1. 出馬表・結果のデータにある `waku` を使う（`entries[].waku` / `ranked[].waku` / 結果行の `waku`）
2. 無いときだけ計算: 8頭以下＝馬番そのまま。9頭以上は 外側の枠から2頭ずつ（`gen.py` の `waku()` と同じ式）
3. 取消で頭数が変わっても枠は変わらないので、計算は「出走表の頭数」で行う
