# 「買い方別 回収率」の1枚　設計書

2026-11-14。ユーザーの質問「3連複を◎○の2軸から流した時、3連単の頭を◎固定で流した時、3連単の頭を◎○で流した時、○から流した時、○◎の2軸から流した時も追加できる？」。
→ 見本を見て「それでいいよ」。**実装済み（v4.3.74）**。見本: `docs/design/buyways/b1_buyways.png`（数字は全部架空）。

## 1. 答え
- できる。必要な払戻（3連複・3連単・馬連・馬単・ワイド）は、今の答え合わせでもう読んでいる。足すのは数え方だけ。
- 予想・印は変えない。

## 2. 足す買い方（相手＝印のついた残りの馬。◎○▲△△の5頭に印がある時の点数）
| 言われたこと | 数え方 | 1レースの点数 |
|---|---|---|
| 3連複を◎○の2軸から流す | 3連複 ◎ー○ー相手（▲△△） | 3点 |
| 3連単の頭を◎固定で流す | 3連単 ◎→相手→相手（○▲△△から2頭） | 12点 |
| 3連単の頭を◎○で流す | 3連単 1着が◎か○、2・3着は残りの印4頭から | 24点 |
| ○から流す | ○を軸に、相手は◎▲△△の4頭。馬連・馬単・ワイド・3連複・3連単1着固定・3連単マルチ（※1枚目の「○軸 合計」は相手から◎を除いた別の数え方） | 4・4・4・6・12・36点 |
| ○◎の2軸から流す | 3連単 ◎→○→相手 と 3連単 ○→◎→相手（順番つきの2頭軸。3連複は上の◎ー○ー相手と同じ） | 3点ずつ |

※「○◎の2軸」は 3連単で1着○・2着◎ に固定する買い方と読んだ。違っていたら直す。
印が5頭に満たないレースは、付いている印の頭数で点数が減る（今の表と同じ扱い）。

## 3. どこに出すか
- **回収率の画像を1枚足す**（「買い方別 回収率」。夜の投稿の、場別回収率の次）。
- 今の「回収率」の1枚目は変えない。**総合計にも入れない**。
  理由: 入れると総合計が今までと別の数字になり、過去の日と比べられなくなる。投稿の文の「全部の券種の合計」も変わってしまう。
- 3つの段: ◎を軸／◎と○の2頭を軸／○を軸。比べやすいように、今ある ◎3連単マルチ・◎3連複 も ◎の段に並べる。
- 各行: 買い方・1レースの点数・回収率（緑／赤）・的中数・収支。

## 4. 仕組み
- `deploy/tweet.html` の `calcRecovery()` に数え方を足す（今の項目には触らない＝今の数字は変わらない）。画像は `drawBuywaysCanvas()` を新しく作る。
- 自動投稿の側は変えなくてよい（夜の回の画像が1枚増えるだけ）。

## 5. 確認のしかた
- 1レースを手で数えた結果と合うか（◎1着固定・2軸・1着が◎か○・○1着固定）。同着のレースも1つ見る。
- 今の「回収率」の画像と投稿の文の数字が、足す前と1円も変わらないこと。
- 11/13 のデータで実物を出す。

## 6. 注意（盛らない）
- 1日ぶん（40レースほど）の回収率は、大きい配当が1本あるだけで大きく動く。この表は「その日はどうだったか」で、「この買い方が得」という意味ではない。
- 長い期間でどの買い方が良いかを言うには、別に過去データで数える必要がある（まだやっていない）。
