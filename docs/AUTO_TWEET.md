# 自動ツイート仕様

**目的**: 今まで手作業でやっていた「アプリで生成 → 📋コピー → 𝕏に貼る → 画像添付」を自動化する。
投稿内容そのものは**既存の生成関数をそのまま使う**（新しい文面は作らない）。

対象アカウント: @kaji_keiba
最終更新: 2026-07-19 / **未実装（設計段階）**

---

## 方針

スコアリングは tweet.html の JavaScript の中でしか動かない。サーバーのPHP cronからは叩けない。
→ **puppeteer で tweet.html をヘッドレスで開き、既存関数から文と画像を取り出して X API に投げる。**

PHPへの移植は**しない**。GBMとスコアリングの二重実装になり、片方だけ直して食い違う。

起動は Windows のタスクスケジューラ。PCが起動している必要がある。

## 1日の流れ

| # | タイミング | 内容 | 使う既存実装 |
|---|---|---|---|
| ① | 各レースの**発走15分前** | 出馬表画像＋展開＋見どころ。狙い目なら絵文字でアピール、見送りなら見送りと明示 | `drawShutubaCanvas` / `raceFlowText` / `raceFocus` / `betPlan` |
| ② | レース確定後 | 的中したレースと当たった券種 | `hitTweetText` |
| ③ | 1日の終わり | 回収率・場別成績などのまとめ | `drawRecoveryCanvas` / `drawVenueRecoveryCanvas` / `timelineCheckText` / `drawFukuHitCanvas` |

対象は**全場**。

### ① 発走15分前の予想
- 15分前にする理由は**オッズが必要**だから。⭐(高知ファイナル)も狙い目/見送りの判定も人気を使う
- 印そのものはオッズ非依存。オッズを使うのは「買い方」の層だけ（AUDIT v307）
- **見送り判定が出たレースも投稿する**。「見送り」と明示する
  - 高知ファイナルは ⭐0-1頭 なら見送り推奨（⭐2頭以上で回収169%、⭐0-1は妙味薄）
  - 平場は betPlan の tier（勝負/複勝/様子見/見送り）に従う
- 狙い目のときは絵文字でアピール。既存のバッジ体系に合わせる:
  - 💰 妙味（⭐条件に合致・データ裏付けあり）
  - 🎯 勝負（gap8以上）
  - ⭐ 高知ファイナルの人気薄先行

### ② 的中ツイート
- `hitTweetText` が「【園田7R レース名】🎯 馬連 7.8倍！ 的中 ◎1 馬名 →1着…」を生成する
- 5的中以上は自動で1行ダイジェストに圧縮される（v325。的中列挙がうるさい問題は対処済み）
- 答え合わせは `checkRace`。確定済みはキャッシュされ、未確定の先頭で打ち切られる（v326/v327）

### ③ 1日のまとめ（どれを貼るか）
実装済みのうち、**この3点に絞る**のが良いと考える:

1. **回収率画像** `drawRecoveryCanvas` — ◎軸の券種別内訳つき（v346）。1日の成果はこれが本体
2. **時系列まとめ** `timelineCheckText` — 1レース1行で「NR ◎着順 🎯最高配当券種X倍」。流れが分かる
3. **複勝的中率画像** `drawFukuHitCanvas` — 全場合算に対応済み（v350）。「当たってる感」を出す拡散用

`drawVenueRecoveryCanvas`（場別）は全場やるなら情報量が多すぎるので、**まとめには入れない**。
週次でまとめる方が向いている。

## 数字の扱い（誇張しない）

FACTS.md の通り、**地方の平場は回収率では勝てない**（◎複勝78-81%）。
- 平場の投稿で「黒字」「回収率○%で勝てる」と書かない。価値は**精度＝的中率**で見せる
- 黒字と言ってよいのは高知ファイナル⭐フォメだけ。それも「過去成績・未来保証なし」を併記
- 小サンプルの高回収を煽らない（38R/145% が大規模で61%になった前例がある）

## X API

- OAuth 1.0a（画像アップロードに必要）。**アプリ権限を Read and Write にする**（既定は Read only）
- 必要なキー4つ: API Key / API Secret / Access Token / Access Token Secret
- 投稿数に月次上限がある。**全場×15分前だと1日数十件になるので、上限を実装前に確認する**
  - 上限に当たる場合は、対象を「勝負/狙い目が出たレース＋高知ファイナル」に絞る
- 自動投稿は X の自動化ルールの対象。同一文面の連投・高頻度はスパム判定のリスクがある

### 認証情報の置き場所
`deploy/x_credentials.json`（**.gitignore 済み**）に本人が記入する。
Claude はこのファイルを読まない。スクリプトが読み込んで使う。

}
