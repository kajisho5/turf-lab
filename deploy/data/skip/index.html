「見送り」のレースは、本当に見送るべきか

地方競馬 171,046レースを「読みやすさ」で5段階に分けました。
調べ始めたときの想定と、結論が逆になりました。

1. ゾーンの分け方

1位と2位のスコア差で、そのレースが「読めるか」を5段階にしています。 差が大きいほど、抜けた1頭がいるレースです。

◎の複勝回収率は84.6% → 76.7%と、 きれいに右肩下がりです。ここまでは想定どおりでした。

2. ところが、回収率は動きませんでした

◎から○▲△へワイド3点を買った場合です。

どのゾーンでも67〜68%。振れ幅はわずか0.8ポイントでした。

同じ買い方の的中率は、鉄板62.2% → 見送り46.4%と15.7ポイントも違います。 当たりやすさはこれだけ違うのに、戻ってくる金額の割合は変わらない。

オッズが、当たりやすさの差をきれいに吸収しています。
読みやすいレースは配当が安く、読みにくいレースは配当が高い。 その交換比率が、ちょうど釣り合う位置に置かれているということです。

これは市場がよくできているという話であって、 「見送りゾーンを買えば儲かる」という意味ではありません。 67〜68%は、どのゾーンでも大きな負けです。

3. 見送りゾーンにしかないもの — 配当の裾

◎を1着に固定して○▲△へ流す3連単6点で、 実際に出た最高配当を比べます。

見送りゾーンの最高配当は554,300円。 鉄板ゾーンの27,640円に対して約20倍です。 的中率は7.0%と低く、14レースに1回しか当たりません。

「見送りレースは当たらないが、当たると大きい」——これは実測どおりでした。 ただし3連単の回収率も58.9%で、やはり100%には届きません。

4. で、結局どうするのか

この集計から言えるのは、次の2つだけです。

① ゾーンは「当たりやすさ」を教えるが、「儲かりやすさ」は教えない。
的中率を上げたいなら鉄板ゾーン。ただし回収率は変わらないので、 買う量を増やしても損失が増えるだけです。

② 見送りゾーンの価値は、配当の裾にある。
14レースに1回の的中を待てるなら意味がありますが、 その間ずっと負け続けます。資金と気持ちの両方が要ります。

※ 当サイトでは回収率100%を超える買い方は見つかっていません。 43通りの戦略と条件別の総当たりを試して天井は92.2%でした。 このページの数字も、その事実を覆すものではありません。

5. このページの作り方

データは keiba.go.jp の公式データです。 回収率は必ず「買った全レースを分母」にしています。 的中したレースだけを分母にすると、回収率は簡単に水増しできます。

ゾーンの分け方（スコア差のしきい値）は以前から使っているもので、 この記事のために都合よく決め直してはいません。 しきい値を後から動かすと、どんな結論でも作れてしまいます。
