近走データが少ない馬は、買えないのか

予想に使えた近走の数ごとに、◎の複勝率と回収率を比べました。当サイトの予想は過去の走りを土台にしているので、データが少ない馬ほど不利なはずです。

結果

いちばん差が出るのは3連複で、「2走ぶん」の62.5%から「1走ぶんだけ」の56.1%まで6.4ポイント開きます。複勝でも3.2ポイントの差があります。

予想が外れました（いい意味で）

このページを作った動機は「材料が少ない馬ほど当たらないはずだ」でした。 当サイトの予想は近走の記録を土台にしているので、 1走ぶんしか無い馬は不利で当然、と思っていたからです。

結果は逆でした。近走が3走ぶん以上ある馬の複勝率が、 いちばん低く出ています。素直に読めば 「データが揃っている馬ほど当たらない」ということになりますが、 そんなはずはありません。

これは、人気の違いが混ざった見かけの逆転です

近走が1〜2走しかない馬は、キャリアの浅い馬や休養明けの馬です。 そういう馬を当サイトの予想が◎に選ぶとき、 その馬はたいてい人気側にいます （少ない材料で本命に推せるほど目立つ成績、ということなので）。 一方3走ぶん揃っている馬は、人気薄も含めた全体に広がります。

各マスは「レース数 ／ 単勝回収率 ／ 複勝回収率」。 500件に満たないマスは数字を出していません。 集計対象は◎173,728レースです。 複勝だけでなく単勝も併記しています—— 複勝はいちばん当たりやすい＝配当が削られる券種なので、 条件による差が実際より小さく見えるためです。

人気を揃えると逆転が消えます。 とくに4番人気以下では、近走が多い馬ほど回収率が高いという 本来予想したとおりの並びに戻ります。 1番人気の中ではほぼ横並びで、これも納得できます。 1番人気に推されるほどの馬なら、材料が1走ぶんでも判断が付くということです。

教訓としては、全体の集計だけを見て因果を語ると足をすくわれるということです。 このページは、その実例としてそのまま残しています。

この数字の読み方の注意

当サイトが保持している近走は直近3走までです。 「3走ぶん以上」には通算10戦の馬も100戦の馬も含まれます。 この表は「キャリアの長さ」ではなく 「予想を組む時点で材料が何走ぶんあったか」を見ています。 デビュー間もない馬のほか、長期休養明けの馬もここに入ります。

読むときの注意

ここに出ている回収率はすべて100%を下回っています。条件を選んでも、それだけで勝てるようにはなりません。当サイトでは43通りの戦略と条件別の総当たりを試し、天井は92.2%でした。

回収率は7つの券種すべてで出しています。 複勝はいちばん当たりやすい＝いちばん配当が削られる券種なので、 条件による差が小さく見えます。複勝で差が無くても、単勝や3連単では はっきり開いていることがあります。
買い目の形は先に決めて固定してあります（◎＝当サイトの本命、○▲△＝スコア2〜4位）: 単勝◎/複勝◎ 各1点、ワイド・馬連・馬単は◎-○▲△の3点、 3連複は◎絡み3点、3連単は◎1着固定で○▲△を並べ替えた6点。 集計してから良かった買い方を選ぶことはしません（それは検証ではなく後知恵の選抜です）。

回収率は必ず「買った全レースを分母」にしています。 的中したレースだけを分母にすると、回収率は簡単に水増しできます。 区分の切り方はこの記事のために決め直したものではなく、 backtest/analyses.py に固定してあります。
