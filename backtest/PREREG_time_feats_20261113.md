# 事前登録: 時計の項目を順位学習に足す（2026-11-13 08:00・実行前に記入）
背景: 本番の順位学習33列には「走破タイム」「上がり3F」「最高タイム」から作った列が1つも無い（着順・着差・先行度だけ）。
　　　公式データには全場・全期間で入っている。「モデルに無い軸」に当たる。
列（全部、前走までの情報だけで作る）:
- sf1/sfb/sfa … 近3走の時計指数（場×距離×馬場の、それまでの勝ち時計の中央値 − 自分の時計。200mあたり秒）の 前走/最良/平均
- af1/afb/afa … 近3走の上がり指数（そのレースの出走馬の上がり3F平均 − 自分の上がり3F）の 前走/最良/平均
- btf … 今日の出馬表の「最高タイム」を今日の場×距離の基準と比べた指数
候補: +sf(3列) / +af(3列) / +bt(1列) / +全部(7列)
選抜: 2021年（2021年より前で学習）と2022年（2022年より前で学習）だけで行う。
　　 2年とも複勝◎回収率の差がプラスの候補のうち、（単差+複差）の2年平均が最大のもの1つ。該当なしなら終了（不採用）。
最終評価: 選ばれた1つだけを 2023-01〜2026-11-12 で1回。
合格: 複勝◎回収率の差の95%範囲（レース単位2000回・種20261113）の下限>0、かつ単勝◎の差が0以上、かつ4年のうち3年以上で複がプラス。
　　 さらに C12（今の補助モデルを足した並び）にしても複が下がらないこと。
合格しても本番には入れない。ユーザーに数字を出して判断をもらう（索引・画面側の配線が要るため）。
