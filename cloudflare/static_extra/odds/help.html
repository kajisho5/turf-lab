ODDS ANOMALY / 使い方

オッズの異常な動きを検知し、期待値で「買う・見送る」を判断する競馬ツール

このアプリの核

勝つコツは「当てる」ことより「期待値がプラスの時だけ買い、それ以外は見送る」こと。人気や感情ではなく、①オッズの異常な動き（資金の流れ）と②馬の近走実績、この2軸で淡々と判断する。全馬が見送りなら「買わない」が正解。

1はじめの3ステップ

1
JRA / NAR を選ぶ
上のタブで中央競馬（JRA）か地方競馬（NAR）を切り替え。開くと自動でその日の開催一覧を取得する。
2
レースをタップ
「データ取得・レース選択」の中に場・R番号の一覧が出る。見たいレースをタップ＝出走表とオッズを自動取得。
3
自動更新をON
あとは放っておけば一定間隔でオッズを取り直し、動きを検知する。締切が近いレースほど直前の動きが重要。
JRAのオッズは当日朝の発売開始後から取れる（おおむね9時前後〜各レース順次）。発売前は「まだオッズ未発売」と出る＝正常。地方は開催時間帯に取得できる。

2現在レースバー・締切

画面上部に常に固定表示される。今どのレースを見ているか（場・R・レース名・頭数）と、発走までのカウントダウンが出る。

  • 締切◯分前 … まもなく締切。色が変わって警告
  • 締切間際! … 残り2分以内。点滅
  • 発走済 … もう走った

馬券は締切時刻が命。スクロールしても上に残るので、夢中で分析してても買い逃さない。

3買い目・期待値（EV）

このアプリの心臓部。各馬の期待値（EV）= 推定勝率 × オッズを計算する。

EV値意味
1.00 超理論上プラス。買う価値がある
1.00 未満理論上マイナス。基本は見送り

パネルの先頭に判定が出る：

  • 買い候補◯頭 … EV1.0超の馬がいる。最有力馬とEV値を表示
  • 見送り推奨 … 全馬EV1.0未満。市場が適正＝無理に張らないのが回収率を守る

単勝／複勝を切り替え可能。各馬に推奨投資額（ケリー基準）も出る（予算の何%を張るべきか、上限10%で安全側）。

推定勝率は「市場オッズ（控除率80%反映）＋異常検知の補正＋過去の学習実績」から算出。データが溜まるほど精度が上がる。

4馬連・ワイド・3連複（JRA限定）

急落で資金が入った馬を軸に、相手との組み合わせ期待値を実オッズで計算。馬連／ワイド／3連複を切替。

合成オッズ・トリガミ判定

EV1.0超の点が複数ある時、「全部まとめ買いしたら」を自動計算：

  • 均等回収配分 … 各点いくらずつ張ればどれが当たっても同額戻るか（100円単位）
  • 合成オッズ … まとめ買いの実質倍率
  • ⚠ トリガミ警告 … 合成が1.0未満＝当たっても損。点数の広げすぎを止める
地方（NAR）は複勝・馬連オッズのAPIが提供されていないため、この機能はJRAのみ。地方は単勝EVで判断する。

5異常検知のタグ

オッズの動きから「資金がどう動いたか」を検知してタグ表示する。

🔻急落オッズが大きく下がった＝資金流入＝評価急上昇。最重要シグナル
🔺急騰オッズが上がった＝見限られた
⚡直前急変締切間際の急な動き。プロの資金が入った可能性
🔀単複乖離単勝と複勝の支持にズレ＝玄人筋の置きにいく資金の気配

スコアは「本命〜中波長（2〜10倍）の急落」を重く、万馬券（超人気薄）の動きは軽く評価する。ノイズに振り回されないための重み付け。

6◎○▲△ 印の意味

印はオッズ（人気）を一切見ない。馬の近4走の実績だけで評価する。だからオッズが動いても印は変わらない。上位5頭に ◎○▲△△ が付く。

評価の中身（すべて自動・手入力不要）

  • 総合近走力 … 着順を頭数で正規化＋人気を上回ったか。新しい走ほど重視
  • ★同じ回りでの実績 … 今走が左回りなら過去の左回り成績を加点（右回り左回りの得手不得手）
  • 同じ芝/ダ適性・同距離帯適性
  • 決め手 … 上り3F（ラスト600m）が速い馬を加点
  • 馬場×脚質 … 不良・重なら逃げ先行馬を加点

馬名をタップ → 近走履歴が見られる。今走と同じ回りには白枠の印が付くので、「この馬は左回り得意か」が一目で分かる。着順は1着=緑、3着内=橙。

印（近走実績）と検知（オッズの動き）は別の軸。「実績ある馬（◎）に資金も入った（🔻急落）」が重なる時が最も信頼できる。

7資金フロー

どの馬に金が流れたかを左右バーで表示。左=資金流入（評価↑）／右=見限られ。

  • 累積（初期表示）… 見始めてからの合計の動き。取得を繰り返しても消えない。本命がじわじわ買われてるのも追える
  • 直近 … 今のステップの動き。「今まさに動いてる馬」を見たい時

8全Rウォッチ司令塔

開催全レースを一覧して、急落が大きいレース＝資金が動いてる＝妙味を上位に表示。1レースに張り付かず「おいしいレースだけ拾う」ための司令塔。

サーバー（cron）が裏で集めたデータを読むので、あなたの端末に負荷はかからない。急落15%超のレースは赤くハイライト。タップでそのレースの監視に飛ぶ。

中身が出るのは、サーバーがしばらくデータを集めた後（開催時間帯）。空なら「アクティブなレースなし」＝正常。

9結果・答え合わせ

発走後のレースで「着順を取得」を押すと、確定着順と検知の答え合わせができる：

  • 上位3着（馬番・馬名・人気）
  • 検知トップは何着だったか
  • ◎本命は何着だったか
  • EV買い目が的中したか

出走表にも着順バッジが重なる（1着=緑、3着内=橙）。「あの検知は正しかったか」を後から検証できる。

10仮想ベットと回収率

買い目の「張る」ボタンで紙トレード記録（1点100円）。後で「ベット結果反映」を押すと実際の着順で回収率（ROI）を自動計算。

「このアプリの言う通り買ったら儲かるか」を実弾を使わずに検証できる安全装置。本番投入前にまずここでデータを貯めるのが賢い。

11自己学習・傾向

監視したレースの検知と結果が自動で記録され、溜まると見えてくる：

  • トップ検知の勝率・複勝率
  • タグ別の的中率（🔻急落は複勝率◯%、など）
  • 場別・条件別の傾向（この場は堅い／荒れる、勝ち枠の偏り）
  • 自動チューニング（10レース以上溜まると、検知スコアの閾値を提案）

「サーバー同期」を押すと、cronが集めたデータも取り込まれて学習が育つ。サーバーURLは最初から入っている。

12コツ・注意点

勝つための使い方

  • 見送りを恐れない。 全馬EV1.0未満なら買わないのが正解。市場が正しい時は勝てない
  • ◎（実績）と🔻急落（資金）が重なる馬が最も信頼できる
  • 締切間際の急変は情報量が多い（プロの金）。直前まで見る
  • まず仮想ベットで数週間。 回収率を見てから本番。机上の理論より自分のデータ
やらない方がいいこと： 3連単・WIN5のような点数が爆発する馬券は期待値計算の誤差が大きく、このアプリでは扱わない。トリガミ警告が出たら点数を絞る。

13困ったとき

「未発売」が出るJRAは当日朝の発売開始前。少し待つ。締切間際なのに出るなら、別の開催中レースで確認
データが出ない開催が無い日・時間帯かも。日付と開催を確認
更新したのに変わらないアプリを一度削除→ブラウザで開き直して再追加（古いキャッシュを捨てる）
全Rウォッチが空サーバーがまだデータ収集中。開催時間帯に再度「更新」
印がしっくり来ない近走の少ない馬や、出走表取得前は精度が落ちる。馬名タップで近走を確認
